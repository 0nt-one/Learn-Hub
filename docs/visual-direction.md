# Learn-Hub 视觉方向

2026-11-11 用户确认。后续页面样式以本文为准；旧 UI 规范中冲突的视觉细节逐步迁移，业务和可访问性要求保留。

## 核心方向

Apple 式极简主义、几何构成、蓝白品牌色。简约但不单调，科技但不浮夸，专业但不冰冷。首页、资源中心、详情、个人中心和管理后台沿用同一系统。

- 背景：纯白、极浅灰蓝；主色 `#155EEF`，统一使用 `--lh-primary`。
- 辅助色：低饱和薄荷绿、淡紫、浅橙；资源类型为文档蓝、视频紫、链接绿。
- 几何元素：圆角矩形、圆弧、细线、半透明色块；用 CSS/SVG 构成，作为轻量点缀，不覆盖文字。
- 边框：1px 浅蓝灰；阴影柔和、低存在感；容器圆角 12–20px。
- 排版：标题、正文、元信息层次明确，信息密度和可读性优先。
- PageHeader：中文标题上方使用主题蓝、小号、大写英文眉题；通过必填 eyebrow 属性传入具体页面英文名。
- 动画：仅轻微位移与透明度等过渡，并尊重减少动态效果偏好。
- 不使用随机 AI 插画填充页面；不滥用渐变、玻璃拟态、发光效果；减少无意义图标与重复标签。
- 资源卡片：白底、几何角饰、明确标题和两行摘要、课程/更新信息；整卡点击进入详情，保持键盘可访问。

本次先落地主题主色、PageHeader 和资源中心卡片。其他旧页面后续按此规则逐页统一，不代表已全部重做。浏览器视觉验收由用户执行。
